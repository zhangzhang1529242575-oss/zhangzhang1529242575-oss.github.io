关于这张研究网络

METHODOLOGY & CAVEATS

这张图把电机领域的人、机构、师承与技术路线放在同一张可交互的网络里，用于快速建立领域地图，而不是做学术评价。

收录范围

  • 三个相互咬合的方向：电机本体设计（电磁/热/结构）、驱动（电力电子与系统）、控制（无位置传感器、MPC、伺服等）。
  • 以高校/研究所课题组为主，兼收少量产业界代表人物；覆盖中国内地与香港、欧洲/英国、北美、日韩澳。
  • 每人给出机构、主要方向、2–3 个主题标签与一句研究特色说明。

四种关系

  • 师承（橙色箭头）：以博士导师/团队负责人为主，方向为导师 → 学生。
  • 合作（蓝色虚线）：公开的共同作者、同中心同事或长期合作。
  • 同团队 / 同机构（灰色点线）：同一课题组或同一院系，由机构字段自动生成，可在筛选器中关闭。
  • 同方向（紫色点线）：编辑判断的技术路线相近（如无位置传感器、集成绕组双端口），不代表正式合作。

可信度标记

每条关系带可信度：● 已核实（学校主页/IEEE 传记/博士论文）；◐ 较可信（多方资料一致但未逐一核对原始来源）；○ 待核实（公开资料不足，图中以稀疏虚线显示）。界面中把鼠标放在关系上可看到依据说明。

学者层级

为了区分“大牛”和青年学者，图中加了一层编辑标注：资深（院士 / IEEE Fellow / 国家杰青 / 讲席或荣休教授，41 人）、中坚（62 人）、青年（博士毕业约 12 年内，或入选优青/青托等青年人才计划，9 人）。资深节点带银环（院士仍用金环），青年节点带蓝色虚线环；左侧“学者层级”可只看某一层，或一键把青年移出主图。

怎么用

  • 点 师承脉络 只看导师—学生链；点 中国团队 / 欧洲 / 北美 看区域格局。
  • 点 集成绕组 / 双端口 进入“曲荣海 → 牛双霞”的二度关系视角。
  • 选中一位学者后，右侧面板列出导师、学生、合作者与同机构同事，可继续点击漫游。
  • 用 学者层级 或“资深学者 / 青年学者”视角，区分资深 PI 与青年学者；点“青年学者：移出主图”可得到一张只有资深/中坚的干净网络。
  • 用主题标签（永磁、无轴承、风电、电动汽车……）交叉筛选，找交叉方向的人。

局限

① 关系数据来自公开资料，无法覆盖“私下合作、短期访学、企业项目”等弱关系；② 师承以博士导师为主，博士后/团队负责人关系未单列；③ 任职与头衔会变动，个别信息可能滞后；④ “同方向”是编辑判断，仅供导航，不作为事实引用。用于论文或申报材料前，请以学校主页与原始论文为准。
